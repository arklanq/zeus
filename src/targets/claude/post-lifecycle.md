A Worker reports its result, question, or blocker in two steps; require both in the assignment and forbid the Worker from reporting through `SendMessage`. First, it writes the full report to `~/.zeus/workstreams/<workstream-id>/outbox/<Name>-<YYYYMMDD-HHMMSS>.md` by writing a `.tmp` file in that directory and renaming it to `.md`, creating `outbox/` if needed. Then it ends its turn with a final message that begins with `Message from {Name}:` and repeats the report. The application continues an idle Coordinator with a note quoting the first 400 characters of that message, but only when no other Worker is running, so the outbox is the Coordinator's reliable signal.

While any of its Workers is running, the Coordinator keeps exactly one outbox watcher: the Bash command `until ls ~/.zeus/workstreams/*-<zeus-id>-*/outbox/*.md >/dev/null 2>&1; do sleep 5; done; ls ~/.zeus/workstreams/*-<zeus-id>-*/outbox/*.md` with `run_in_background: true` and `timeout: 1800000`. The application wakes the Coordinator when the watcher exits. On every wake, whether from the watcher, its timeout, or an application note, the Coordinator reads every report in its outboxes, moves each one to `outbox/read/` in the same workstream once it is recorded in the registry, and then starts a new watcher if Workers are still running and none is active. After a timeout with no report, it checks the running Workers through `get_session`. A turn started by another session's message cannot start sessions, while a note or watcher wake also lets the Coordinator start the Workers it unblocks. Do not poll the sessions otherwise.

When `SendMessage` to a Worker is refused because the application limits how many messages the Coordinator may send since the user's last message, do not look for substitute tools. Tell the user which Workers await which messages and that their next message lifts the limit.

When the user asks for progress or a Worker is silent for too long, inspect the session through `get_session` and `list_events` and present a concise status rather than a transcript; `stop_session` stops the Worker's turn.
